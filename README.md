## 1 先想清楚用来做什么

| 你的情况 | 先看哪个 |
|---|---|
| 日常问答、写东西，每天用一会儿 | ChatGPT Go / Plus，或 Claude Pro |
| 每天大量使用，经常碰到用量上限 | ChatGPT Pro，或 Claude Max |
| 写代码，用 Codex 或 Claude Code | 先买 ChatGPT Plus 或 Claude Pro 用一周，看用量够不够，再决定要不要升级 |
| 2 人以上的团队，要统一付款和管理 | ChatGPT Business，或 Claude Team |

两家的用量都不是固定的"每天多少条"，而是按模型、任务大小和对话长度来算。最稳妥的做法是**先买入门档，用一周，看用量面板再决定升不升级**。

## 2 ChatGPT 各套餐

官方价格（美元 / 月，不含税）：

| 套餐 | 官方价格 | 官方定位 |
|---|---|---|
| Free | $0 | 免费试用；Codex 只能做简单的小任务 |
| Go | $8 | 轻量使用；Codex 适合轻量编程任务 |
| Plus | $20 | 日常主力；Codex 够每周几次专注的编程 |
| Pro | $100 起，分三档：<br>$100（用量约为 Plus 的 5 倍）<br>$200（约为 Plus 的 20 倍）<br>$500（用量最高，含 Ultrafast 模式） | 每天重度使用 |
| Business | 年付 $20 / 人 / 月（2 人起）<br>月付 $25 / 人 / 月 | 团队：统一管理，默认不用业务数据训练模型 |

几点说明：

- Plus 有每 5 小时的用量上限，另外可能还有每周上限；官方说 Pro 目前没有 5 小时上限。
- Codex 包含在 ChatGPT 的各个套餐里（Free、Go、Plus、Pro、Business、Edu、Enterprise），和 ChatGPT 共用同一份用量。
- 用量不够时，可以另外购买官方的 ChatGPT credits（额度）。

## 3 Claude 各套餐

官方价格（美元，不含税）：

| 套餐 | 官方价格 | 用量和功能 |
|---|---|---|
| Free | $0 | 网页、桌面和手机都能用；**不含 Claude Code** |
| Pro | 月付 $20 / 月<br>年付 $200（约合 $17 / 月） | 每 5 小时的用量至少是 Free 的 5 倍；含 Claude Code |
| Max 5x | $100 / 月 | 每 5 小时的用量是 Pro 的 5 倍；输出上限更高，高峰期优先；每月附 $100 API 额度 |
| Max 20x | $200 / 月 | 每 5 小时的用量是 Pro 的 20 倍；其他同 Max 5x；每月附 $200 API 额度 |
| Team | 标准席位：年付 $20、月付 $25 / 人 / 月<br>高级席位：年付 $100、月付 $125 / 人 / 月 | 团队：统一付款、单点登录；高级席位的用量是标准席位的 5 倍 |

几点说明：

- 网页、桌面、手机和 Claude Code **共用同一份用量**，按 5 小时滚动重置，付费套餐另外还有每周上限。
- Max 只能按月付。
- 用量用完后，可以等它重置、升级套餐；付费套餐也可以打开 usage credits，按 API 标准价继续用。

## 4 写代码选 Codex 还是 Claude Code

| | Codex（OpenAI） | Claude Code（Anthropic） |
|---|---|---|
| 包含在哪些套餐里 | ChatGPT 所有套餐，从 Free 开始 | Claude Pro 及以上，Free 没有 |
| 用量 | 和 ChatGPT 共用 | 和 Claude 聊天共用 |
| 用量不够时 | 升级套餐，或另买 ChatGPT credits | 升级到 Max，或打开 usage credits |
| 用 API Key | 可以，按 API 价格另算，和订阅分开 | 可以，按 API 价格另算，和订阅分开 |

**怎么选：** 两个都能用的话，先各买入门档（ChatGPT Plus / Claude Pro）用一周，看哪个更顺手、用量够不够。一个人轻度写代码，入门档通常就够了；每天要长时间跑任务，再考虑升级到 Pro 或 Max。

一个实例：作者自己一行代码都不会写，用 Claude Pro 加 Claude Code，花了大约 3 小时做出一个能公开访问的网站，第二天早上 4 分钟发布上线。

## 5 自己开通还是找人代充

**能自己开就自己开。** 有官方支持的付款方式，就直接在官网或官方 App 里订阅，最省心，也能随时在账号设置里取消。

自己开不了的话，常见的办法是找人代充。但"代充"其实是三种完全不同的东西：

| 方式 | 是什么 | 风险 |
|---|---|---|
| 充到你自己的账号 | 账号是你的，订阅显示在你自己的账号设置里 | 最小 |
| 成品号 | 别人注册好的账号，卖给你用 | 账号不在你手里，原主随时可能改密码或找回 |
| 共享号 / 拼车 | 多人同时用一个账号 | 违反官方条款，容易触发风控；聊天记录别人也能看到 |

## 6 共享号和成品号的风险

OpenAI 和 Anthropic 的用户条款都**明确不允许共享账号**：

- OpenAI 使用条款：*"You may not share your account credentials or make your account available to anyone else"*（[原文](https://openai.com/policies/row-terms-of-use/)）
- Anthropic 消费者条款：*"You may not share your Account login information… You also may not make your Account available to anyone else."*（[原文](https://www.anthropic.com/legal/consumer-terms)）

另外：

- 多人在不同地方同时登录一个账号，容易被判定为异常。
- 你的聊天记录和上传的文件，同一个账号里的其他人都能看到。
- 账号被封了，订阅也就没了，这种情况一般没人负责。

## 7 找代充前问清楚 5 件事

1. **充到谁的账号上？** 最好是充到你自己的账号，充完能在自己账号的订阅页面看到。
2. **钱怎么付，没充上怎么办？** "先付钱后办事"是这一行最常见的纠纷来源。下单前先问一句：没充上怎么办？
3. **质保范围说清楚了吗？** "终身质保""永久售后"听着好，但越说不清，出了问题越容易扯皮。问清楚保多久、哪些情况不保。
4. **价格是不是低得离谱？** 比正常价格低很多的，想想便宜是从哪来的。来路不明的卡或渠道，可能过几天订阅就被撤销了。
5. **出了问题能不能找到人？** 有没有固定的联系方式、回消息快不快，下单前多问几个问题就能感觉出来。

## 8 常见问题

**充上以后怎么确认？**
登录官网，在账号设置里的订阅或账单页面，能看到当前是哪个套餐、什么时候续费。

**用量用完了怎么办？**
等它重置（两家都是按 5 小时滚动重置，另外有每周上限），或者升级套餐、购买额外额度。具体剩多少，看官方的用量面板。

**价格会变吗？**
会。两家都写明了价格和套餐可能调整。本页标了核对日期，过时了欢迎提 Issue。

**Codex、Claude Code 需要单独买吗？**
不用。Codex 包含在 ChatGPT 的套餐里，Claude Code 包含在 Claude Pro 及以上的套餐里。只有用 API Key 时才按 API 价格另算。
